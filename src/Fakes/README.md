# Fakes

Імітації чужих систем (POS, PSP), кожна — окремий процес зі своїм власним "незручним" форматом
даних. Формат обирається чесно (не підлаштовується під наші canonical-моделі), щоб адаптер, який
його мапить, і contract tests, які це перевіряють, мали сенс.

## Структура

```
Fakes/Taiken.Fake<System>/    наприклад Taiken.FakePos, Taiken.FakePsp
```

## Правила залежностей

- `Taiken.Fake<System>` → **нічого з `src/`**. Спільні типи з рештою рішення зробили б мапінг
  у відповідному адаптері (`Integrations/<Kind>/Taiken.<Kind>.Fake`) нечесним і замаскували б
  реальні відмінності форматів, які й перевіряють contract tests.

Перевіряється `Taiken.ArchitectureTests` (з M2).
